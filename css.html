CSS Basics

CSS (Cascading Style Sheets) is used to style and layout web pages.

What is CSS?

CSS is used to style HTML elements and control the presentation of a webpage, including colors, fonts, spacing, and layout.

Ways to Add CSS

CSS can be added in three ways:
  • Inline - using the style attribute
  • Internal - using the <style> tag
  • External - using a separate CSS file

CSS Selectors

Selector Example Description
Element p Selects all <p> elements
ID #header Selects element with id="header"
Class .container Selects all elements with class="container"
Universal * Selects all elements
