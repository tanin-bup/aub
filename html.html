HTML Basics

HTML (HyperText Markup Language) is the standard markup language for creating web pages.

What is HTML?

HTML is used to describe the structure and content of a webpage. It uses a set of tags to tell web browsers how to display text and media.

HTML Elements

An HTML element is everything from the start tag to the end tag:

<tagname>Content goes here...</tagname>

Common HTML Tags

Tag Description
<h1> to <h6> Headings
<p> Paragraph
<a> Hyperlink
<img> Image
<div> Division/Container
